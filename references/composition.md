# 按完整页面复现论证与画面

先打开对应的完整预览，再读取原生对象。这里的参照不仅是颜色、校标与字体，还包括图像在论证中的作用、区域比例、证据的定位方式、阅读顺序和结论位置。不能只取页型名称，再用通用分栏重新设计。

## 先做内容角色映射

为选定模板页记录：`区域 / 论证作用 / 用户材料中的对应内容 / 图像来源 / 与其他区域的关系`。主图、局部、解释、设计要求不能混换。参考页是局部放大，新内容也应有可定位的真实局部；如果新内容只有并列结果，就另选适合对照的页型，不用放大引线制造错误关系。

保持版式骨架：页眉下的内容起点，主图与说明的面积比，说明分组的位置，连线与颜色对应，结论的落点。允许按真实内容调整尺寸，不能将这些关系全部改成等宽栏或小表格。

以下坐标使用 1280 × 720 画布。打开 PPTX 后复用这些原生区域，填充用户材料；坐标帮助理解骨架，不要求每次从零重画。

## 复现检查

渲染新页与所选参考页并排看，检查：主图尺度和位置是否相当；多尺度图像关系是否保留；分组、引线、强调和结论的位置是否承担同样作用；阅读顺序是否能跟着证据走。先检查论证关系，再检查画面。

参考页有大图与四组定位解释，新页只有小图加三列短句，即使颜色、字体、页数正确也不算复现。信息密度来自保留下来的证据、对应关系和必要解释。不能通过重复文字、无关配图、统一缩小字号制造密度。

中文使用微软雅黑，英文与数字使用 Arial。正文通常黑色；深蓝用于页眉，红色用于少量关键结论，彩色框与浅底用于确实对应的解释分组。不要把所有正文改为深蓝或绿色，也不要机械地禁止本页实际需要的底部结论条。不同页型保持各自的结构。
