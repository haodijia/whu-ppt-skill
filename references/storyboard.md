# 从材料到页面

## 按任务决定页面结构

| 用户材料或任务 | 应建立的主线 | 页面选择依据 |
|---|---|---|
| 学位论文，多项贡献 | 总体问题、贡献之间的关系、各章证明、总结 | 背景只解释一次；每项贡献独立建立问题—方法—验证链；目录章数跟随真实贡献 |
| 单篇论文介绍 | 论文问题、核心思路、方法机制、实验依据、局限与讨论 | 标明作者工作；无需套成四个研究章节；方法篇幅由理解难度决定 |
| 开题或研究设想 | 需求与缺口、研究问题、拟采用的方法、验证计划、进度 | 未完成实验只写计划；不能用结果版式暗示已有结果 |
| 阶段性汇报 | 目标、已完成工作、关键结果、存在问题、下一阶段 | 聚焦相较上次新增的内容；背景可压缩 |
| 已有 PPT 重制 | 保留正确论证，修正冗余、跳步和证据位置 | 先检查哪些页重复、哪些结论没有证据，再选版式 |
| 仅给零散图表 | 图表回答的问题、比较条件、证据能支持的结论 | 缺失方法或图表语义时核实，不根据图像外观编写研究结论 |

## 构建逻辑关系

先做一张内部对应表：`研究问题 / 现象证据 / 现有方法不足 / 设计依据 / 方法模块 / 验证实验 / 可支持的贡献`。

检查每列能否接上：
- 背景中的问题，应由方法或研究范围回应。
- 方法中的新增设计，应在实验或论证中得到验证。
- 总结中的贡献，应能回指具体方法和证据。
- 未来工作应接续真实局限，而非添加无关热点。

同一章节通常依次说明：问题观察、设计思路、整体方法、关键模块、数据与协议、对比实验、消融或机制分析、典型场景。材料不足或讲解不需要的环节不硬凑。

## 决定拆页与合页

- 一个页面承载一个主要讲解任务。标题相同的两页可以分别解释同一框架的不同模块。
- 一张方法图同时需要讲输入表示、内部计算和训练策略时，保留同一总图，按模块拆页或按点击分步解释。
- 多列比较必须采用相同字段，例如“思路、代表工作、不足”。若每列都需要长篇论述，应拆页。
- 对比实验和消融实验回答不同问题，不因二者都有表格而机械合并。
- 一页无法让听众辨认关键图像差异时，减少案例数，保留最能支持结论的案例。
- 用户指定页数时先在该限制内安排必要内容。页数和内容要求确实冲突时解释具体冲突，不静默删掉必需证据。

## 页型计划字段

每页记录：`页号 / 目的 / 标题 / 一句话核心信息 / 来源位置 / 页型与构图 / 主图和补图 / 讲解顺序 / 点击状态 / 当前缺项`。

示例：
`背景页 / 解释数据来源选择 / 遥感影像的作用 / 覆盖范围与更新方式回应现有生产限制 / 材料第X节 / 左右比较 / 传统采集过程照片＋遥感获取示意 / 先传统后新来源再结论 / 无必需动画 / 缺卫星获取示意`。

## 导航

目录的章节名称与最终内容一致。长报告在章节开始时重复目录，并只强调当前章。短报告可减少重复过渡页。编号、条目数量与当前项根据实际章节设置，删除多余条目后重新分配间距。
