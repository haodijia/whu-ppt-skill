# 从材料到有证据的讲解

## 先读什么

论文先读问题定义、方法图及图注、关键计算、实验设置、主结果、消融和局限；图表中的小标题与注释也是材料。文稿先标出事实、推论、实例和结果，再找支撑它们的原始图表。不能只凭摘要与结论生成整份研究汇报。

建立内部对应表：`问题 / 观察证据 / 已有不足 / 设计依据 / 方法机制 / 验证 / 可支持的贡献`。不能接上的列表示论证缺项，不能用转折词补齐。

先完成进入方法前的两步：背景用真实场景说明对象、任务和约束；问题发现用具体案例、分布、对照结果或理论条件指出困难，再说明设计要回应什么。两步可以在短报告中合页，不能都被一句“现有方法存在不足”替代。研究动机、事后消融和未来设想保持各自的时间与证据属性。

## 不同任务的主线

| 任务 | 组织依据 |
|---|---|
| 单篇论文 | 具体问题与已有缺口；输入/输出与机制；支持设计的实验；局限 |
| 多篇论文 | 先比较问题定义、对象、输入输出与假设，再分别解释机制；在可比条件下综合结果。不能因任务名称相似就跨论文直接排数值名次 |
| 学位答辩 | 背景只解释一次；各项贡献分别建立问题、方法与验证链；说明贡献之间的依赖 |
| 开题/设想 | 问题、依据、拟用方法、验证计划；明确计划与已完成工作 |
| 阶段汇报 | 本阶段新增工作、关键结果、未解决问题和下一步 |
| 已有 PPT 重制 | 检查重复、跳步、缺证据和读图困难；保持正确的研究含义 |

两篇表示学习论文的比较可以贯穿同一个对象实例：输入怎样表达，经过哪些变换，输出编码保留什么，怎样训练，新对象怎样获得表示，哪些实验支持这些差异。不得把这一组织示例中的方法或事实直接套给其他论文。

共同背景可以合并，各篇论文仍须讲清自己的问题依据、机制和验证，不能变成“每篇一张架构图 + 最后一张对比表”。不同论文的数字只有在数据、指标与协议可比时才进入同一排名；不可比时比较任务条件和设计选择。模板中的 SAM 与 ViT 是独立的页型示例，不能将它们的章节编号或跨论文顺序照搬到成稿。

## 一页包含多少内容

讲解任务决定内容边界。解释一个机制往往需要输入例子、运算或公式、输出变化及原因；证明一个效果往往需要比较条件、完整相关数据、可视化和分析。保留这些互相支持的部分。

- 只有一句定义或三个短框时，先检查是否漏了原图、实例、公式或证据；也可能应该与相邻页合并。
- 公式页保留符号含义与具体输入输出，不能只展示公式名。
- 方法页保留关键计算与分支关系，不能把整套结构改成“输入—编码—输出”三级方框。
- 结果页保留决定结论的对照方法、数据集、指标方向和误差定义。不得只挑两个有利数字。
- 拆页适用于不同论证任务，或缩放后无法读清的细节。拆分时保留总图定位，避免重复背景与结论。
- 篇幅受限时先删重复铺垫、合并稀疏页面，再决定取舍。用户指定时长或页数时遵守该范围；必要内容确实无法容纳时说明具体冲突。

## 逐页计划

每页写：`讲解任务 / 标题 / 必须保留的细节 / 来源节、图、表 / 主证据与补图 / 图中观察位置 / 版式及示例页 / 图文对应关系 / 与前后页的关系 / 动画理由或静态`。

例如“输入表示”页可包含：输入尺寸、分块样例、序列长度计算、投影后的形状和位置编码作用。这些围绕同一任务组织，无需拆成五张只有一句话的页。

最后把标题连起来读，再检查每个关键结论能否回指一页具体证据。目录跟随成稿内容；短报告不机械重复章节过渡。
