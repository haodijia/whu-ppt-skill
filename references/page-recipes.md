# 逐页制作方法

按页面承担的讲解任务选择构图。相同页型可以重复使用，信息关系改变时应调整布局。

| 页型 | 制作顺序与定版标准 |
|---|---|
| 封面 | 根据汇报需要填写标题、汇报类型、作者、单位和日期；采用建筑照片与留白形成主次，长标题合理分行，不侵入照片主体 |
| 目录与章节过渡 | 先确定真实章节，再设置编号与当前项；采用圆形编号和横向细线。删除多余行并重新均分间距 |
| 应用需求与价值 | 先定“应用场景 / 能力与限制 / 研究价值”的关系，再安排左图右文；主图服务场景，底部只落一个有依据的判断 |
| 路线或数据来源比较 | 左侧按真实流程排列过程图片，右侧展示新来源；分别给限制和优势，结论明确二者关系 |
| 问题诊断 | 先选能看出问题的案例，再确定问题数量；用编号和局部标记建立图文对应，分组数量跟随实际问题 |
| 研究现状 | 按方法思想分组；每组同样顺序展示思路、代表工作和不足。代表图应能解释差异 |
| 研究目标与内容 | 先建立问题与方法的对应关系，再排问题、关键思路、研究内容；箭头只表示实际依赖或对应关系 |
| 问题观察与设计依据 | 每行先给现象图，再说明原因与设计思路；目标必须能由观察推出 |
| 方法架构与模块讲解 | 总图展示输入、模块、连接和输出，必要时增加局部放大；高亮与说明一一对应，按讲解顺序设置点击动作 |
| 数据与设置 | 数据来源或分布图配合样本、标注和实验协议表；填写划分方式、单位和公平比较条件 |
| 对比实验 | 先整理指标与方向，再选能解释数值差异的案例；各列使用同一案例、同一裁切、同一图例；最后写证据支持的结论 |
| 消融实验 | 先明确改变的变量与控制组，再排表格和对应图像；说明贡献和代价，避免将多因素变化都归于一个模块 |
| 大范围结果 | 主图保证空间关系完整，局部放大与主图框选对应；保留图例、尺度和必要区域说明 |
| 多阶段流程 | 先列各阶段的输入、操作、输出和传递关系，再排节点与细节；逐步讲解时高亮当前阶段并保留整个流程 |
| 工作总结 | 每项贡献包含所解问题、提出的方法和支持证据；项目数对应真实贡献，压缩论文式长段落 |
| 局限与展望 | 每项未来方向接续一个具体局限，写可执行的研究方向 |
| 结束页 | 与封面保持一致的建筑与校标构图；一句结束语即可 |

## 背景页完整制作例

以“遥感影像为何适合地图构建”为例：

1. 从材料提取需要支持的比较：传统采集流程的成本、覆盖或更新限制，与遥感数据的对应特点。没有证据的优势不写。
2. 采用左右比较构图。排好左侧传统流程、右侧新来源和底部判断，确定左侧小图与右侧主图的目标比例。
3. 盘点现有素材。已有采集车照片就直接使用；缺少卫星获取示意时，先检索对象和工作方式。
4. 检索真实照片时，记录原页面、作者或机构、可用性以及图像尺寸。下载后查看原图，确认主体与场景，不只依据搜索缩略图。
5. 需要生成概念图时，写与版面匹配的提示词。例如：“航空与卫星遥感获取地表信息的科研示意，俯视城市道路，主体位于画面中央偏右，横向构图，干净浅色背景，无文字、无标识，左侧留出少量空间，图像用于说明获取方式，不表现实测结果。”实际生成工具与模型按当前环境和用户指定执行。
6. 将图放入预定位置，检查关键主体是否被裁断、照片风格是否冲突、相邻图的尺度是否合理。必要时重新裁切或重新生成。
7. 用原生文本补充流程名称与解释，以细线或必要箭头串联。图片中不嵌入大段说明。
8. 最后检查：读者能否仅凭图文理解“现有路线的限制”和“新来源为何有帮助”。不支持这一关系的素材删除。

## 方法页完整制作例

1. 从方法描述提取真实输入、模块、连接和输出。先把结构图与论文核对，再谈配色。
2. 保留整体框架的位置，选择本页需要解释的局部，放大到正文主区域。右侧每段只解释一个计算或作用。
3. 以听众阅读顺序建立说明编号。高亮覆盖对应的最小完整区域，不遮住连线与公式。
4. 将每个高亮与说明配成一步。上一步高亮退出、当前高亮进入、当前说明出现，放在同一次点击中。
5. 已讲说明始终保留。所有说明按阅读顺序分开放置，不共用重叠文本框；最后一步应能同时读到全部文字。
6. 按初始状态和所有点击状态查看，尤其检查第一个高亮是否过早出现、最后一个是否残留到下一页，以及倒退后是否恢复正确。
