# 方法图与解释文字联动

## 行为

整体方法图和解释区标题始终可见；初始时高亮与分步说明隐藏。按照实际模块数量安排点击步骤。右侧说明自上而下逐条出现，已出现的文字一直保留；黄色高亮随当前说明切换，上一处高亮消失。以下以四步讲解为例：

| 状态 | 当前高亮 | 说明 | 本次动作 |
|---|---|---|---|
| 初始 | 无 | 全部隐藏 | 展示整体框架 |
| 第 1 次点击 | H1 | T1 | 同时出现 H1、T1 |
| 第 2 次点击 | H2 | T1、T2 | 隐藏 H1，同时出现 H2、T2；保留 T1 |
| 第 3 次点击 | H3 | T1、T2、T3 | 隐藏 H2，同时出现 H3、T3；保留 T1、T2 |
| 第 4 次点击 | H4 | T1、T2、T3、T4 | 隐藏 H3，同时出现 H4、T4；保留 T1、T2、T3 |

先按全部说明可见的最终状态排版，为每条文字安排独立位置，避免重叠。文字过多时压缩说明或拆页，不将已讲文字隐藏来腾位置。

## 制作

- 高亮形状独立于底图，使用透明度约 60% 的浅黄色填充，可加细黄色边框。图中标签与公式仍需可读。
- 通用页的对象命名为 `HIGHLIGHT_1…N`、`EXPLAIN_1…N`，编号连续并一一对应。
- 每一组动作的首项设置为“单击时”，其余设置为“与上一动画同时”；不使用自动计时跳到下一模块。
- 文字只设置进入动画，不设置退出动画。黄色高亮设置进入与退出，当前高亮进入与上一处高亮退出在同一次点击中完成。
- 整体方法图不退出、不移动。复制页面解释另一模块时，总图位置、尺度与图例保持一致。
- 需要全部内容随时可读的静态分享稿应另行设计；不能用多张重复静态页冒充已经完成原生动画。

## 写入原生动画

先完成布局和 PPTX 导出，再运行随附脚本。脚本只重建指定页的这套联动动画，因此不要用于已有其他需要保留动画的页面。

```bash
uv run --no-project --with lxml python scripts/apply_focus_animation.py \
  --input draft.pptx --output animated.pptx --slide <目标页码>
```

脚本按对象名称读取最终形状 ID，写入一条原生点击序列，并验证引用存在。若对象缺失、编号不连续、输入输出相同或输出已存在，明确报错。

之后不要再通过会重建幻灯片的导入导出流程，否则动画可能丢失。修改文字或移动同一对象可以保留其动画；删除并新建对象后应重新绑定。

复制整个原生示例页时，保留 `p:timing`、`p:bldLst` 与目标对象 ID 的映射；复制备注必须新建独立备注部件及回指，不能让两个幻灯片共用同一备注部件。复制含公式的图形时保留命名空间与 AlternateContent 的声明。

## 检查

检查 XML 只能证明动作与对象引用存在。必须在 PowerPoint 放映中查看初始状态和每次点击，确认当前文字与高亮同步出现、已讲文字全部保留、上一高亮消失、图像没有被隐藏、点击没有跳过步骤，并测试退回与重新进入该页。仅检查 PDF 或静态缩略图不能证明动画正确。
