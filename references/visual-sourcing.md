# 主动获取与使用图像

## 按论证找素材

先为重要内容建立素材清单：`需解释的对象 / 所需证据或图像 / 原始出处 / 目标页面 / 裁切范围 / 获取状态`。这张表保留在工作目录，不进入幻灯片。

| 用途 | 获取方式 |
|---|---|
| 论文方法、实验和消融 | 优先提取原论文图表、补充材料、作者项目页；保留图注并核对正文。原生数据图可依据完整数据重建 |
| 文稿中的真实对象、设备、场景 | 主动检索官方机构、项目或原始摄影来源，查看实际图片与来源页面。仅有文字不意味着不需要图 |
| 抽象概念说明 | 优先用真实输入实例或可编辑技术图；需要场景插画时使用图像生成，明确示意用途 |
| 背景装饰 | 仅在有构图作用时使用；不能替代研究证据，也不为每页强行装饰 |

论文已经有足够合适的图，不必为“搜索过”再加外部图片。材料不足时应实际执行检索，而不是在计划中写“可搜索配图”后省略。只下载已核实用途的资源；图片搜索结果是线索，不是来源。

## 获取后必须看图

- 查看原图或 PDF 对应页，记录图号、图注、子图含义、单位和来源。
- 方法图保证模块名称与箭头关系可读。需要局部细节时用“总图定位＋局部放大”，不要把缩小整图当成已经解释机制。
- 结果图保持同一案例、裁切和图例。不要把不同案例排列成同一对象的前后对照。
- 一个证据图可以连贯地用于总览和局部解释，重用应有新的讲解任务。
- 外部图片找不到或无权使用时明确该素材缺口；不静默换成无关图、生成实验图或空框。

生成图提示词应说明用途、主体、空间关系、比例和留白。文字、校标、公式、数据与实验结果不交给图像生成模型。引用写入页备注，署名要求落实到图注。
