# 内容与视觉验收

先检查研究信息是否充分，再检查技术文件。无溢出、可打开只是必要条件。

## 逐页对照

将当前页与同任务的模板示例并排查看，逐项判断：

1. **具体性**：能否指出实际对象、操作、变量、比较条件？删掉方法名后若可套给任何论文，正文仍过于抽象。
2. **解释完整度**：听众能否从输入追到输出，从图表读出结论？必须存在的计算、示例或对照是否被缩写掉？
3. **证据可读性**：读者能否看清关键模块、坐标、图例和差异？大面积留白旁却放着极小证据图，应重排。
4. **图文关系**：说明是否指出图中具体区域、数据行或现象？不能靠装饰图和一句总结通过。
5. **结构保真**：主图与说明的比例、局部定位、分组解释、连线、关键词强调和结论位置对应所选参考页；没有将这些结构改造成通用分栏。说明框与结论条是否使用，由参考页的论证作用决定。
6. **行文**：标题清楚，说明包含必要条件，结论有支持；没有口号、编造收益和制作说明。

背景页需能沿着真实场景读出任务及约束；问题发现页需能在证据中定位差异，再找到与它对应的设计要求。只列“背景 / 挑战 / 贡献”几个标题，或将多个问题缩成三个抽象方框，均未完成这两类页面。

同类示例存在主图、局部、比较和解释时，检查新页是否保留了任务所需的相应层次。允许按内容改变构图，但不能以“简洁”为由将已有的关键证据和关系删掉。问题定位优先用图中编号、对应色、局部放大或对齐对照，不要求读者自行寻找文字所指的位置。

局部放大检查实际裁切范围与定位框是否一致；不同预测之间的对照不能画成放大关系。彩色引线必须到达对应案例及说明区。结构检查未通过时，不以“页数增加、没有溢出、字体合规”替代复现判断。

发现内容稀疏时补回被遗漏的真实内容或合页，不能靠复制句子、添加无关图片、缩小字号堆砌来“达标”。同样，材料只支持简单解释时，不强行增加信息。

## 全稿检查

- 背景提出的问题在方法中有回应，主要设计在实验中有验证。
- 多篇论文的关系贯穿具体差异；实验的可比与不可比部分清楚。
- 全稿缩略图显示内容驱动的布局变化，正文页并非同一模板反复换标题。
- 背景、方法、实验的构图确实承担不同任务；不能只改分栏比例而保持每页同一组短句。先复核材料最充分的页面，若仍普遍只有一图三句，重新检查内容提取与页内组织。
- 目录、页码、来源、图例与单位一致。每张内容页在正常放映尺度上可阅读。
- 动画清单只含有明确空间定位需求的复杂方法页，简单流程与比较表保持静态。

## 文件与分发

- 图表和文字保持所需编辑性。检查母版、媒体关系、备注回指、公式和动画对象引用。
- 生成时删除旧示例内容及未使用部件，不把看不见的旧素材带进交付文件。
- 可分发 skill 与模板只包含允许分发的素材；检查 PPTX 的隐藏页、备注、媒体、嵌入文件、批注及作者元数据，不只检查可见页面。
- 无法完成的具体放映或来源检查应如实交代，不把 XML 检查说成实机放映验证。
